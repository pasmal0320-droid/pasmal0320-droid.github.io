원칙 5가지

  1. 원칙1지어내지 않는다. 공고 문장마다 원문 근거를 두고, 없거나 엇갈리면 확인 필요
  2. 원칙2근거는 폴더 안 원문으로만. 조문은 법령 파일에서 읽고 ID로 인용, 없으면 "근거 미확인"
  3. 원칙3결론 내리지 않을 것은 넘긴다. 예외 해당 여부, 학력 요건, 확정 안 된 약속은 검토
  4. 원칙4기밀과 개인 신상은 공고 밖에. 공개 등급 "공개" 항목만 사용
  5. 원칙5리포트는 "법령 대조 점검(1차)". 법적 검토를 했다고 쓰지 않는다

발표 순서 5 · 이것을 해도 되는가

애매했던 점 네 가지와 판단 과정

애매한 점판단과 극복 방법남은 위험
회사 직무기술서·프로젝트 자료를 외부 AI에 넣어도 되나사내 기밀(고객사명·계약금액)과 재직자 정보가 섞여 있어 그대로는 안 된다고 판단했다. 가상 회사·가상 데이터로 개발했고, 실무에서는 회사가 승인한 AI 도구에서만 쓴다.실제 문서에는 가상 데이터보다 다양한 형태의 기밀이 섞인다
AI가 쓴 공고를 그대로 게시해도 되나공고는 외부 공개 문서이고, 채용 후 근로조건을 불리하게 바꾸면 과태료 대상이다 FH-4③ FH-17. 그래서 스킬은 초안까지만 만들고, 근거 없는 근로조건은 쓰지 않으며, 확인 필요 블록과 담당자 확인란을 둔다.담당자가 확인 없이 그대로 게시할 가능성
기밀·개인 신상이 공고에 새지 않나사내 정보공개 기준으로 공개 등급 "공개"만 쓰게 했다. 결과물 생성 스크립트가 공고와 리포트에서 금지 정보를 찾으면 결과물을 만들지 않고 멈추며, 리포트에서도 원문을 가린다 PI-17.금지 목록에 오르지 않은 정보는 기계 검사에 걸리지 않는다
AI의 법령 판단을 믿을 수 있나기억으로 조문을 쓰지 않고 폴더에 넣은 원문만 ID로 인용하게 했다. 예외 해당 여부는 결론 내리지 않고 검토로 넘기며, 리포트 제목을 "법령 대조 점검(1차)"로 했다. 폴더에 없는 병역법은 "근거 미확인"으로 표시되었다.법령 원문은 공식 사이트가 아닌 사본에서 옮겼다. 인용이 붙어도 그 조문이 판단을 뒷받침하는지는 사람이 확인해야 한다
